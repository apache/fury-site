# Publication cover prompt

Use case: ads-marketing.
Create one polished raster release poster for a Chinese WeChat article introducing Apache Fory JSON for Kotlin. Exact landscape aspect ratio 2.25:1, target pixel dimensions 2304 × 1024. Edge-to-edge composition with no outside border or letterboxing.

Article title: Apache Fory™ JSON：面向 Kotlin 的高性能 JSON 序列化.
The article explains Kotlin-aware JSON mapping (constructor defaults, nullability, value classes and sealed types) built upon Fory's high-performance JSON engine. Communicate efficient structured data moving between Kotlin types and JSON, with a restrained engineering technology aesthetic.

Design: deep midnight navy background with a subtle indigo-to-dark-blue gradient, ice-blue and cyan lighting, subtle finely drawn technical grid, generous clean negative space. High-end digital 3D illustration, precise geometry, frosted glass and brushed metallic materials, crisp professional editorial typography. Cold colors throughout, no orange, red or warm gradients.

Composition: strong text area across the left 60 percent, a striking sculptural pair of glowing JSON curly braces and layered translucent data plates on the right 40 percent. Thin parallel cyan data streams pass cleanly through the braces; a few discrete square particles suggest structured data. Use restrained luminous edges, dimensional depth, and controlled motion lines. Keep the text background quiet and readable. The diagram is abstract, not an actual architecture diagram. No extra labels. Maintain 7 percent safe margins so text and key illustration remain uncut.

Visible text, exactly, with these line breaks:
Apache Fory™ JSON
面向 Kotlin 的
高性能 JSON 序列化

The first line is a large bold clean geometric sans-serif white wordmark with a small superscript trademark symbol. The two Chinese lines form the title below it in a beautifully rendered bold modern sans-serif Chinese font, with 'Kotlin' and 'JSON' legible in matching Latin type. Use ice-white title text with a restrained cyan accent. Strong hierarchy, balanced spacing, highly legible at mobile cover size. Spell every Chinese character and English word correctly. Do not add punctuation, feature lists, version numbers, claims, benchmark ratios, subtitles, badges, buttons, QR codes, URLs, fake logos or watermarks. Only the three exact title lines and the abstract data visualization should appear.

The result should feel like a premium open-source infrastructure product launch: sophisticated, crisp, uncluttered, and technically grounded. Avoid generic robots, brains, rockets, server-room photos, noisy cyberpunk decoration, excessive glow, and long code snippets. This must be a finished designed poster, not a screenshot of a design application or a mockup.
